# Подключение к Live Chat из локальной сети

## Твой компьютер (сервер)

**IP адрес**: `10.101.0.65`

**Оба сервера запущены**:

- Backend WebSocket: `http://10.101.0.65:3000`
- Frontend приложение: `http://10.101.0.65:5173`

## Для других людей в сети

### Шаг 1: Узнай IP адрес хоста

Скажи им IP адрес твоего компьютера: **10.101.0.65**

```
http://10.101.0.65:5173
```

### Шаг 3: Перейдите на Live Chat

- Откройте приложение
- Нажмите на "Live Chat" в меню

---

## Требования для подключения

- ✅ Оба человека в одной локальной сети
- ✅ Backend запущен на портах 3000 (HTTP + WebSocket)
- ✅ Frontend запущен на порту 5173
- ✅ Firewall разрешает доступ к этим портам

---

## Как найти свой IP адрес на macOS

Если нужно изменить IP в конфиге:

```bash
# Найти IP
ifconfig | grep "inet " | grep -v 127.0.0.1

# Результат будет похож на:
# inet 10.101.0.65 netmask 0xffffff00 broadcast 10.101.0.255
```

Затем обновить `/frontend/.env.local`:

```
VITE_BACKEND_URL=http://10.101.0.65:3000
```

## Структура работы

```
┌─ Компьютер1 (10.101.0.65) ─┐
│  ✅ Backend (3000)          │ ◄──── WebSocket сервер
│  ✅ Frontend (5173)         │
└─────────────────────────────┘
           ▲
           │ HTTP/WebSocket
           │
      ┌────┴──────┐
      │            │
┌─────▼───┐  ┌────▼──┐
│ User 1  │  │User 2 │
│Browser1 │  │Browser2│
└─────────┘  └────────┘
```

Все пользователи подключаются через WebSocket к одному серверу, сообщения тут же транслируются всем.

## Отладка


В консоли браузера (F12 → Console):

```javascript
console.log("Connected:", document.querySelector(".status-dot.connected"));
```

### Проверить логи

- Backend: смотрите консоль где запущен `npm run start:dev`
