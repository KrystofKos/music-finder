# Live Chat Implementation - Music Finder

## Что было сделано

Подключен лайв чат с WebSocket поддержкой между фронтенд и бэкенд.

### Backend структура

**файлы:**

- `/backend/src/chat/chat.gateway.ts` - WebSocket gateway для обработки сообщений
- `/backend/src/chat/chat.module.ts` - модуль для подключения к приложению
- `/backend/src/app.module.ts` - обновлен для подключения ChatModule

**Функционал:**

- Автоматическое подключение клиентов
- История последних 100 сообщений
- Broadcast всем подключенным клиентам
- Обработка события `sendMessage` с форматом `{ user: string, text: string }`

### Frontend структура

**файлы:**

- `/frontend/src/api/useChat.ts` - React hook для работы с WebSocket
- `/frontend/src/components/Chat/Chat.tsx` - компонент чата
- `/frontend/src/components/Chat/Chat.css` - стили
- `/frontend/src/pages/LiveChat.tsx` - страница чата (обновлена)

**Функционал:**

- Автоматическое подключение к серверу
- Сохранение имени пользователя в localStorage
- Автоскроллинг к последним сообщениям
- Статус подключения (зеленая/красная точка)
- Отправка сообщений с Enter (Shift+Enter для перевода строки)

## Как работает

1. **Подключение**: Когда пользователь открывает страницу LiveChat, `useChat` hook автоматически подключается к WebSocket серверу на `http://localhost:3000`

2. **История**: Сервер отправляет историю всех сообщений новому клиенту при подключении

3. **Сообщения**: При отправке сообщения, браузер отправляет `sendMessage` событие. Сервер получает его, сохраняет и отправляет всем подключенным клиентам

4. **Реактивность**: React автоматически обновляет интерфейс при новых сообщениях

## Запуск

```bash
# Terminal 1 - Backend
cd backend
npm run start:dev

# Terminal 2 - Frontend
cd frontend
npm run dev
```

Откройте http://localhost:5175 в браузере и перейдите на страницу "Live Chat"

## Особенности

- Сообщения хранятся в памяти (будут потеряны при перезагрузке сервера)
- До 100 сообщений в истории
- Автоматическое переподключение при разрыве соединения
- Максимум 5 попыток переподключения

## Расширение функционала

Если понадобится сохранять сообщения в БД, нужно:

1. Создать Schema/Model для сообщений
2. Добавить сохранение в БД в `chat.gateway.ts`
3. Загружать историю из БД при запуске
